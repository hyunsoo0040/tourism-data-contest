# PREVIEW v1 review history

This directory preserves noncanonical review iterations for audit and recovery.
`review-rights-v16/` and `review-rights-v17/` remain tracked history.
`review-rights-v18/` is the exact-four snapshot mirrored to the current canonical
preapproval target; earlier iterations and `legacy-canonical-pre-v17/` are
preserved locally unless they are explicitly selected for version control.

Only `fixtures/preview/v1/review/` is the preapproval target. Nothing under this
history directory is eligible for approval or fixture freezing.
