## 검증과 배포 기록

검증 로그·스크린샷·빌드 입력 해시는 `artifacts/ui/place-media-20260914/`에 보관한다. 최종 이미지와 검사 결과는 같은 디렉터리의 `verification.json`을 기준으로 한다.

- 전체 웹 단위 검사 721건을 직렬 실행해 통과했다. 병렬 실행에서 기존 관리 화면의 포커스 검사 한 건이 간헐적으로 실패했으며, 해당 파일 34건의 독립 실행도 통과했다. 관리 화면의 제품 코드나 검증 조건은 변경하지 않았다.
- 구버전 합성 추천 fixture의 점수·관측 자료는 보존하고, 현재 백엔드 생성기로 확인한 추천 실행 해시와 그 실행을 참조하는 ID를 갱신했다. 관광 context는 기존 관측 자료를 유지한 채 실행 ID와 context 해시를 다시 바인딩하고 백엔드 계약 검사를 통과했다.
- 사진 전환, 실제 이미지 픽셀 로딩, 공식 정보, 지도 링크, 상세 이동, 저장, 개별 조회 실패와 복구를 실제 PUBLIC API로 데스크톱·모바일에서 확인했다. 최종 2건 통과.
- 운영용 웹 이미지의 빌드·타입 검사와 모바일 가로 넘침 검사를 통과했다. 기존 추천→비교→저장→기록 흐름도 별도의 실제 API 브라우저 검사 1건을 통과했다.
- 두 브라우저 검사 프로세스를 병렬 실행했을 때 로컬 amd64 에뮬레이션에서 추천 조회의 30초 대기시간이 한 번 초과됐다. 순차 실행으로 통과했으며, 동시 사용자 응답 성능을 검증한 결과로 주장하지 않는다.
- 디자인 탐지의 경고 한 건은 기존 설문 진행 단계의 하단선에 대한 것으로, 이번 사진 UI와 관계없는 오탐으로 기록했다.

TourAPI 재수집, Apify 호출, 유료 모델 재분석, 사람 평가를 실행하지 않았다. 관광지 점수·추천식·PUBLIC 패키지는 변경하지 않았다. 사진에 보이는 계절이나 상태를 현재 운영 정보로 간주하지 않는다.
