# 원본 평가 자료 부재에 따른 검수 절차

2026-09-10 현재 운영 목표는 전국의 볼거리·체험 800~1,000곳이다. 아래 PUBLIC100
검수는 당시 경주 자료의 **역사 기록**이며 새 전국 평가 자료가 아니다. 새 수집·개발 평가
상태는 [전국 실제 자료 수집](nationwide-data.md)을 따른다. 새 개발 실험은 볼거리 24곳과
작성된 상황 3개를 별도 사전 등록하고, 실제 인간 검수·온라인 사용자 60명·방문 경험자
18명 자료는 새로 모집·수집한다. 아직 그 인원이나 인간 평가 점수가 확보된 것은 아니다.

2026-09-09 사용자가 기존 평가의 원본 자료가 없다고 확인했다. 원본 DEV24/BLIND12 목록과
그 목록의 공식 관광지 ID 대응표 복원은 더 이상 대기하지 않는다. 요청한 추천 개선·관광공사
API 연결·사진의 분위기 전용 사용은 구현과 자동 검증을 마쳤다. 실제 사람의 판단을 수집하는
정확도·만족도 평가는 별도의 후속 작업이다.

## 당시 자료로 준비했던 검수

당시 분석 후보는 `b84378d12a31c87107f55ed671dd09025ef8b841a8c7227995233662191a7ff5`이며,
경주의 PUBLIC 장소 100개와 공식 자료를 포함한다. 이 자료로 **출처를 다시 검수**할 수 있다.
100개 전체가 이미 분석·개발에 노출되었으므로 새로운 블라인드 표본으로 취급하지 않는다.
이 검수 풀은 공개 MVP의 장소 선정이나 기존 배포 카탈로그를 변경하지 않는다.

- [검수 목록](../artifacts/evaluation/grounded-review-restart-20260909/review-pool.json):
  현재 장소 ID, 관광공사 ID, 명칭·주소·좌표와 당시 공식 출처를 연결한다.
- [빈 검수 양식](../artifacts/evaluation/grounded-review-restart-20260909/review-template.json):
  사람이 장소 대응, 사실 오류, 자료 누락을 확인할 때 작성한다. 모델 점수·판정과 사람 답변을
  미리 채우지 않는다. 작성 전의 `null`은 미검수이며, 오류 없음이나 점수 0을 뜻하지 않는다.
- [생성 및 무결성 검사](../artifacts/evaluation/grounded-review-restart-20260909/build_review.py):
  고정된 현재 자료에서 목록을 재생성하고 ID·출처 연결과 빈 응답을 확인한다.
  결과는 같은 폴더의 `validation.json`에 기록한다. 검수할 때에는 원본 양식을 복사하여 사용한다.

생성 결과는 고유 장소·관광공사 ID 각각 100개, 공식 근거 346건, 수신 기록 609건이다.
수기 입력 600칸은 모두 비어 있으며, 텍스트·구조화 근거가 없는 1곳도 그대로 남겼다.
동일 입력 재실행에서 목록과 양식의 해시가 일치했다. 외부 API·모델은 추가 호출하지 않았다.

검수자는 공식 자료의 장소 일치 여부와 기준 시점부터 확인한다. 현재 운영·시설 여부를 새로
확인했다면 새 출처와 확인 날짜를 별도로 남긴다. 과거 자료에 없다는 이유로 시설이 없다고
판단하지 않는다. 사진은 분위기 검수에만 쓰며 혼잡·운영·시설 사실의 증거로 쓰지 않는다.
출처의 사실 검수와 방문자가 평가하는 경험·만족도는 다른 결과로 수집한다.

## 기존 검증의 의미

| 자료 | 확인한 범위 | 확인하지 않은 것 |
|---|---|---|
| 기존 PUBLIC 편의표본 24개 개발 실험 | 출처·축 계산·조건 적용·결과 재생의 일관성 | 원본 DEV24의 복원, 대표성, 독립 평가 |
| API·DB·브라우저 검증 | 실제 공급자 응답 처리, 저장된 추천 유지, 화면 표시 | 방문자의 만족도, 실제 장소 경험의 정확성 |
| 새 PUBLIC100 검수 목록 | 현재 장소와 공식 출처의 추적 가능성 | 사람의 검수 완료, 일반화 성능 향상 |

개발 실험은
`artifacts/evaluation/grounded-authority-v2-20260909/dev-manifest.json`에 고정된 기존 편의표본을
그대로 사용한다. 추가 모델 호출이나 동일 실험 재실행은 이번 원본 부재 처리에 필요하지 않다.
기존 해시로 봉인된 산출물·배포 검증·과거 실행 이력은 수정하지 않는다.

현재 PUBLIC 카탈로그에 기록된 과거 `blind_overlap_count: 0`만으로 물리적 중복 부재를
증명할 수는 없다. 원본 식별 자료가 없으므로 **원본 블라인드 표본과의 중복 여부는 미확인**이다.
새 검수 목록에도 이 상태를 명시한다. 현재 ID 대응표가 사라진 과거 대응표의 복원본은 아니다.

## 정확도 향상을 측정할 때

1. 점수 기준, 모델·프롬프트·정책 버전, 비교할 이전·개선 추천식을 먼저 고정한다.
   새 검수 양식은 출처 검수용이며 최종 경험 점수나 사용자 순위 정답 양식은 아니다.
2. 모델의 점수를 보여주기 전에 사람이 독립적으로 출처의 적합성과 경험 항목을 검수한다.
   동일 항목을 두 명 이상이 평가하고 불일치는 근거를 남겨 조정한다. 미확인을 숫자 0으로
   대체하지 않으며, 모델의 답을 사람 정답으로 복사하지 않는다.
3. 현재 100개로 얻은 라벨은 후향 검수·개발 보정에 사용한다. 독립 성능을 주장하려면
   이후에 수집하는 평가 사례와 실제 사용자 응답을 보정 과정에서 분리하고, 결과를 보기 전에
   대상·제외 규칙·평가 방법을 확정한다. 기존 장소를 임의로 24/12로 다시 나누어 과거 평가를
   완료했다고 처리하지 않는다.
4. 동일한 입력·장소·출처 시점으로 이전/개선 결과를 비교한다. 출처 근거의 오류율과 누락률,
   사람과 경험 축의 차이, 실제 관련성 판단에 따른 NDCG@5, 만족도와 불일치 경험을 각각
   보고한다. 표본 수·평가자 일치도·불확실성도 함께 제시한다. 조건 위반 감소만으로 여행자
   만족도 증가를 결론 내리지 않는다.

프로젝트의 온라인 사용자 60명·방문 경험자 18명 평가는 실제 모집과 응답 수집이 필요하다.
현재 생성한 목록이나 자동 검증 결과는 이 인원을 대신하지 않는다. 이 후속 조사는 원본 자료
복원을 기다리지 않고 새 프로토콜로 진행할 수 있다.
