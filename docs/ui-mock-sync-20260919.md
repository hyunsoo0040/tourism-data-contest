# 원격 ui-mock 반영 · 2026-09-19

`origin/itda/ui-mock-20260910`을 fetch하여 `d8ca4190` 이후 최신 커밋 `f45a09177a40153636a23d4ec3e14fff6369f699`의 변경 파일 10개를 현재 작업 트리에 반영했다. 각 파일은 직전 원격 버전과 로컬 내용이 같았으며, 적용 후 최신 원격과 바이트 단위 일치를 확인했다. 최초 반영 단계에서는 브랜치 전환·커밋·push·배포를 하지 않았다.

## 반영한 의도

- 추천 화면의 PC·모바일 메뉴를 홈과 브라우저 뒤로 가기로 정리한다.
- 사진 분위기 입력 제안을 추천 목록 패널 밖의 별도 영역으로 표시한다.
- 사전 로딩한 사진의 DOM을 직접 이동하지 않고 React가 이미지 요소를 생성하도록 한다. 화면 전환 시 DOM 정리 충돌을 피한다.
- 프로필 배너 여백, 상세 정보 버튼 간격, PC 상세 페이지의 한계 설명 줄바꿈을 조정한다.
- 원격의 Netlify 빌드 설정과 `.netlify` 제외 규칙을 반영한다. Netlify 배포는 실행하지 않았다.

## 보존 및 검사 조정

로컬의 프로필 사전 준비·불필요한 재조회 방지, 소개문이 없는 장소의 상세 버튼 유지, 이에 대응하는 테스트를 보존했다. 기존 staged 변경과 다른 작업도 유지했다.

추천 상태 테스트는 새 메뉴 버튼과 구분하여 본문 안의 복구 버튼을 검사하도록 범위를 좁혔다. 브라우저 테스트는 원격의 React 렌더링 방식을 반영했다. 첫 DOM 생성 시 결과·상세 데이터는 준비되어 있지만, 새 이미지 요소의 비동기 디코딩은 그 직후 완료될 수 있다. 첫 DOM 생성 순간 모든 이미지가 디코딩되어 있다는 기존 보장은 유지되지 않는다. 대신 실제 사진 5개의 로딩 완료, 데이터 재조회 없는 전환, 새로고침 복원, 홈 링크·뒤로 가기·사진 입력 이동을 확인한다.

## 검증

- Vitest: 57개 파일, 761개 테스트 통과.
- TypeScript: `pnpm typecheck` 통과.
- Next.js 프로덕션 빌드 통과. 빌드가 자동 수정한 TypeScript 설정은 실행 전 상태로 복원했다.
- Playwright: PC 1440px·모바일 390px에서 추천 전환 및 저장된 설문 재개 4건 통과. 브라우저 오류 및 가로 넘침 검사 통과.
- 화면 캡처 확인: 추천 목록과 별도 사진 제안 영역 배치 확인. 전체 페이지 캡처에서 화면 밖 이미지 일부가 빈 프레임으로 캡처되지만, 브라우저 검사는 사진 5개의 로딩 완료를 별도로 확인했다.
- 디자인 기계 검사: 기존 Inter 글꼴·그라데이션·단계 표시 테두리 경고 4건. 원격 디자인 유지 범위이므로 변경하지 않았다.
- 실행 환경은 Node 24.19.0, 프로젝트 pnpm 11.15.1이다. 선언된 Node 24.18.x와 달라 버전 경고가 있었으며, 선언 버전 환경에서의 재검증은 하지 않았다.

검증 기록과 로그·화면은 `artifacts/ui/ui-mock-sync-20260919/`에 보관했다. 적용 전 파일과 index 패치는 로컬 임시 백업에 보존했다.


## 빌드·푸시 후속 검증

사용자의 빌드·푸시 요청에 따라 원격 `f45a0917`에서 별도 작업 브랜치 `itda/ui-mock-publish-20260919`를 만들었다. 원격의 디자인 변경 10개 파일은 그대로 두고, 로컬의 프로필 전환·상세 버튼 보완과 관련 테스트·이 문서만 추가했다. 푸시 대상은 `origin/itda/ui-mock-20260910`이며 기존 원격 이력을 잇는 일반 push를 사용한다.

별도 작업 공간에서 `pnpm install --frozen-lockfile`, `pnpm build`, `pnpm typecheck`, Vitest 761건을 통과했다. PC·모바일의 설문 완료, 저장된 설문 재개, 추천 전환 경로를 확인했다. 브라우저 검사 도중 히스토리 URL만 확인하고 화면 렌더링을 기다리지 않아 캡처·후속 이동이 경합하는 문제가 드러나, 프로필 화면이 나타난 뒤 앞으로 이동하도록 하고 캡처는 안정된 추천 화면에서 수행하도록 조정했다. 애플리케이션 소스와 빌드 입력에는 이 검증 조정으로 인한 변경이 없다.

기존 작업 공간의 staged 변경은 보존한다. 빌드 산출물·로컬 환경 설정·임시 검증 로그는 커밋에 포함하지 않는다.
