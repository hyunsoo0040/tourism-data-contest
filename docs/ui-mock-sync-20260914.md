# ui-mock 로컬 구현 동기화 · 2026-09-14

`itda/ui-mock-20260910`에 원격 디자인을 반영한 최신 로컬 코드를 우선 적용했다. 원격 `12a3b90`에서 이어지는 커밋이며 원격 이력을 교체하지 않는다.

## 포함 내용

- 전국 PUBLIC 1,984곳의 경험 추천 API, 설문·사진·추천·상세·비교·저장·피드백 화면.
- 메인 6개 최신 관광지 예시와 실제 사진, 추천 결과의 사진·장소 정보.
- 원격 ui-mock의 메인·사진 디자인과 모바일 배치.
- 현재 점수 계산과 근거, 배포 설정, 의존성 잠금, 자동 테스트.
- API 이미지를 빌드하는 데 필요한 검증된 공개 릴리스. 해시는 `bcd012c94cfd1fb66a2edbc3c3922d2e4dfa5438d7d4a86fc9e2f0049b0c79f7`이다.

비밀키·개인 환경 설정·수집 원본·모델 응답 캐시·임시 빌드·로컬 검증 결과는 포함하지 않는다. 수집과 사람 평가를 새로 실행하지 않았다.

## 실행 구분

- 현재 서비스: 메인에서 `/trip`으로 시작한다. 실제 API와 PUBLIC 릴리스를 설치한 DB가 필요하다. [배포 안내](authenticity-deployment.md)와 `deploy/env.example`을 참고한다.
- 기존 합성 UI 목업: `web/`에서 `pnpm dev:mock`을 실행하고 `/start`를 연다. 이 목업의 API는 기존 설문 경로를 위한 것으로 현재 `/trip` API를 제공하지 않는다. [목업 안내](../web/mock/README.md)를 참고한다.
- 프론트 빌드: Node 24.18 및 pnpm 11.15.1에서 `web/`의 `pnpm install --frozen-lockfile`, `pnpm build`를 실행한다.

동기화할 별도 작업 공간에서 웹 테스트 721건과 경험 추천 엔진 테스트 90건을 통과했다. 빌드 입력은 직전 검증한 운영용 웹 이미지와 같은 파일 해시인지 대조했다. 원격 브랜치 반영과 운영 서비스 배포는 별도 작업이다.
