# 중요도와 강도의 추천식 비교

개발120곳의 같은 텍스트 판단과33개 기술 시나리오를 사용했다. 사진·SNS·사용자 사진은 입력하지 않았고 후보·점수·자격 필터·중복 처리·가중치를 고정했다. 추가 API 호출과 사람 평가는 없다.

| 조건 | 강도가 지정되지 않은 항목 | 강도가 지정된 항목 |
| --- | --- | --- |
| 현재 기대 충족식 | 장소 항목 값에 중요도를 가중한다. | `100 − abs(장소 값 − 목표 강도 × 25)`에 중요도를 가중한다. |
| 거리 비교식 | 중요도 값을 목표 강도로 간주해 위 절대차 식에 넣는다. | 사용자가 명시한 목표를 그대로 사용한다. |

거리 비교식은 옛 `100 − abs(...)` 계산을 새 하위 항목에 적용한 대조 조건이다. 옛 설문·옛 H/E/R 정의·분위기·다양성까지 포함한 L0 전체 서비스의 재생 실험이 아니다. 중요도 응답을 강도로 해석하는 것은 실험의 가정이며 실제 사용자의 의도를 확인한 결과가 아니다.

| 입력 종류 | 시나리오 | 자격 후보가 있는 경우 | 상위5 순서가 달라진 경우 |
| --- | ---: | ---: | ---: |
| 중요도만 지정 |30|30|17|
| 목표 강도 명시 |3|3|0|

중요도만 지정한30개 중17개는 중요도2를 포함하고, 이17개 모두에서 순서가 달라졌다. 중요도4만 있는13개에서는 목표100에 대한 거리 식이 장소 값과 같아 순서가 같았다. 목표 강도0·2·4를 각각 명시한3개에서는 두 방식이 같은 명시적 목표를 사용했다. 두 조건의 후보·자료 해시와 제외 내역은 모든 시나리오에서 일치했다.

예를 들어 “역사 경험을 어느 정도 원한다”를 중요도2로 답하면 현재 방식은 확인된 역사 경험이 더 풍부한 곳을 높게 평가한다. 거리 비교식은 이를 “역사 강도50을 원한다”로 간주하므로 중간 강도의 장소를 선호할 수 있다. 사용자가 강도50을 실제로 지정했다면 현재 방식도 그 목표와의 거리를 사용한다. 이는 구현 의미의 차이를 설명하며 어느 쪽이 사람에게 더 좋은지를 입증하지 않는다.

실행 시점은2026-09-12다. 원래 계획은 기본식을 비교한 뒤 정책을 선택하도록 했으나, 실제로는 먼저 의미 설계 판단으로 기대 충족식을 선택·동결했고 이 비교 기록을 나중에 보완했다. 따라서 **사후 개발 점검**으로 표시한다. 새60곳의 독립 확증, 동결 당시의 선택 근거, 최적 추천식이나 만족도 향상 근거로 소급하지 않는다. 동결 정책과 A0–A4·새60곳의 원래 결과는 변경하지 않았다.
