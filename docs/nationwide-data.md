이미 중단된 공급자가 있으면 배치 시작 자체를 거부하며 명시적 재개와 Retry-After를 요구한다.

## 자료 선정과 분석

관광공사의 명칭·ID·지역·좌표 일치를 확인한다. HTML을 정리하고 공백을 제외한 설명이
650자 이상이거나, 400자 이상이면서 유용한 소개 정보가 있는 자료를 선별한다. 확인된
시설 없음·숫자0도 정보로 인정하고 미제공·미확인은 제외한다. 지역별 자료 기회에 비례하되
한 지역의 비중을 제한하고, 시군구·유형 순서를 섞는다. 2026-09-10 사용자 지시에 따라
관광지(12)·문화시설(14)·레포츠(28)만 선정하며, 숙소·음식점은 수집 대상에서 제외한다.
이전 혼합 목적 비율은 폐기했다. 자료 충분성 기준은 유지하고 지역·유형의 실제 분포를 남긴다.
개발 평가는 `--scope sightseeing`으로 볼거리 24곳·작성된 상황 3개를 별도 사전 등록한다.
인간 평가나 블라인드 검증으로 표시하지 않는다.

새 `grounded-source-release.v1`은 장소와 출처의 식별정보만 담는다. 가짜 기존 점수나
모델 신뢰도를 만들지 않고 공식 원문에서 바로 개선된 분석을 실행한다. 미측정 신뢰도는
`null`이며, 추천은 근거가 있는 세부 항목을 집계한 경험 축과 조건·분위기 유사도를 사용한다.

전국 장소의 검색 별칭은 새 공식 명칭과 행정구역 접두어에서만 만든다. 과거 경주 전용
