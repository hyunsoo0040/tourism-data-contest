# IT-DA 관광데이터 활용 공모전

관광데이터를 활용해 사용자의 여행 취향과 기대에 맞는 장소를 추천하는 서비스입니다.

## 주요 기능

- 여행 취향 테스트를 통한 사용자 유형 분석
- 여행 사진을 활용한 선호 분위기 입력
- 취향과 관광지 데이터를 연결한 맞춤 추천
- 추천 결과를 활용한 여행 일정 구성
- Java 기반 추천 API 및 정적 웹 페이지 제공

## 실행 방법

### 웹 화면

프로젝트 루트의 `index.html`을 브라우저에서 열면 메인 화면으로 이동합니다.

### Java 백엔드

프로젝트 루트에서 다음 명령을 실행합니다.

```bash
javac -encoding UTF-8 Backend/ItDaServer.java
java -cp Backend ItDaServer
```

기본 접속 주소는 `http://localhost:5198`입니다.

## 전체 파일 구성

### 프로젝트 루트

| 파일 | 역할 |
|---|---|
| `index.html` | 서비스 시작 페이지이며 메인 페이지로 연결합니다. |
| `README.md` | 프로젝트 소개, 실행 방법, 전체 파일 구성을 설명합니다. |
| `『2026 관광데이터 활용 공모전』 제안서_connector(김현수).pdf` | 공모전 서비스 제안서 원본입니다. |

### Backend

| 파일 | 역할 |
|---|---|
| `Backend/ItDaServer.java` | 추천 API와 정적 파일 제공 기능을 포함한 Java 백엔드 서버입니다. |

### UI

| 파일 | 역할 |
|---|---|
| `UI/메인페이지.html` | IT-DA 서비스 소개와 주요 기능 진입 화면입니다. |
| `UI/메인페이지.css` | 메인 페이지의 레이아웃, 색상, 반응형 디자인을 정의합니다. |
| `UI/메인페이지.js` | 메인 페이지의 메뉴 및 화면 상호작용을 처리합니다. |
| `UI/기능.html` | 취향 테스트와 사진 입력 중 원하는 여행 입력 방식을 선택하는 화면입니다. |
| `UI/취향테스트.html` | 12개 장면을 이용해 사용자의 여행 취향을 분석하는 화면입니다. |
| `UI/사진 기능.html` | 사용자가 좋아하는 여행 사진을 바탕으로 분위기를 입력하는 화면입니다. |
| `UI/기타.html` | 관광데이터 기반 맞춤 추천 기능을 확인하는 데모 콘솔 화면입니다. |
| `UI/기타.css` | 데모 콘솔 화면의 레이아웃과 시각 디자인을 정의합니다. |
| `UI/기타.js` | 추천 요청, 결과 표시, 일정 구성 등 데모 콘솔 동작을 처리합니다. |
